# CRAFT at COLING 2027

Curation, Reproducibility, and Accountability for Training Foundation Models.

Website: https://craft-2027.github.io/

Contact: organizers-craft@googlegroups.com

## Updating the website

Edit `index.html` for workshop content, `style.css` for styling, and `app.js` for the neural-network animation. Organizer photos are in `portraits/`, and `social-card.png` is the sharing image.

GitHub Pages publishes the root of the `main` branch. Changes committed to `main` publish automatically. The site uses static HTML, CSS, and JavaScript and does not require a build step.
